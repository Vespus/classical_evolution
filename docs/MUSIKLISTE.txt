KLANGWANDEL – MUSIKLISTE
========================
Diese Datei wird erzeugt (npm run musiklist). Nicht von Hand ändern, sondern src/data/recordings.json.

So tauschen Sie eine Aufnahme gegen eine eigene Datei:
  Legen Sie in den Ordner media/ (im Projekt: public/media/, auf dem Server: .../klassik/media/) eine Datei,
  die so heißt wie die Kennung unten, z. B. rec-beethoven.mp4 oder rec-beethoven.mp3.
  Möglich: mp4, webm (Video) sowie mp3, m4a, ogg, opus (Ton). Die Datei wird von Anfang bis Ende gespielt,
  schneiden Sie also den gewünschten Ausschnitt vorher zu. Ohne Datei bleibt alles wie bisher.
  Beim Ausliefern per rsync: --exclude 'media/' angeben, damit der Ordner nicht gelöscht wird.

Hinweis zu den Zeitmarken: Titel, Kanal und Länge der Videos wurden technisch geprüft, das Hören der Ausschnitte
konnte dabei nicht erfolgen. Wo eine Startmarke nur geschätzt ist, steht „STARTMARKE GESCHÄTZT“ – bitte einmal anhören.
